# Roube um Ovo 3D para Android

APK Android que abre o Roube um Ovo 3D em tela cheia, com o servidor multiplayer oficial. O jogo é atualizado no site, então novas mudanças aparecem no app sem precisar baixar um APK novo.

## Como baixar

1. Acesse https://github.com/Luis-arch-sketch/Nova-ia-/releases/download/android-apk-v1/Roube-um-Ovo-3D.apk
2. Abra o APK nos downloads do Android e confirme a instalação.
3. Conecte-se à internet e entre na sala multiplayer.

## Notas importantes

- O APK é uma versão de teste instalável (build debug), não uma publicação da Play Store.
- O progresso do Chrome pode ficar separado do progresso interno do APK. Use o backup e a restauração do painel Admin para transferir os dados.
- O servidor multiplayer continua em https://roube-um-ovo-3d-salas.onrender.com/.
- A compilação do APK está em .github/workflows/android-apk.yml.
