# Desenhe um Ovo — protótipo 3D

Jogo web experimental em Three.js. O jogador explora uma praça 3D, entra no estúdio, desenha em papel e transforma a pintura numa textura de ovo 3D para expor. Inclui progressão de moedas por segundo, avaliação local heurística, tutorial, chat local com balões de 10 segundos e interface móvel.

## Publicação
Render Static Site: branch `desenhe-um-ovo-mundo-3d`, publish directory `desenhe-um-ovo`, sem build command.

## Limitações desta primeira versão
A sala multiplayer online com sincronização, chat de voz entre jogadores e o áudio original anexado ainda precisam ser conectados a um servidor/serviço de mídia. O botão de voz apenas solicita permissão de microfone; não transmite áudio a outros jogadores. A avaliação é local e heurística, não um modelo externo.
